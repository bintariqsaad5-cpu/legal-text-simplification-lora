Legal Text Simplifier

A small language model rewrites dense contract clauses as short plain-English summaries. This report compares the original model with the LoRA fine-tuned one on clauses it never saw during training.

Limitations

The dataset is small (a few hundred clauses), so the test set holds only a few dozen, and a small score gap can be noise. ROUGE rewards matching words, not correct meaning, so read the examples before trusting a number. A simplified clause can drop a condition or change its meaning. Output is a reading aid, not legal advice, and does not replace the original contract.
